Which model should we use?

Model 1 has the higher F1 (0.662). Pick it if you want the best balance between false alarms and missed buyers.

Model 2 catches 86% of buyers (recall 0.86), but makes more false alarms. Pick it if missing a buyer costs more than showing an extra ad.

What do these words mean?

Precision: when the model says "will buy", how often is it right?
Recall: out of all real buyers, how many did the model find?
F1: one score that balances precision and recall. We use it because the data is imbalanced: only about 16% of visitors buy, so accuracy alone can fool you.
